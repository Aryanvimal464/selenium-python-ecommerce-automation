# Selenium Python Automation Project

A beginner-friendly Selenium + Pytest Page Object Model project for SauceDemo.

## Requirements
- Python 3.9+
- Google Chrome
- Internet connection

## Setup
```bash
pip install -r requirements.txt
pytest
```

## HTML report
After the run, open:
`reports/report.html`
